# Code of Conduct

## Nosso Compromisso

Estamos comprometidos em tornar a participação neste projeto uma experiência respeitosa, profissional e colaborativa para todos.

## Padrões Esperados

São incentivados:

* Respeito mútuo
* Discussões técnicas construtivas
* Compartilhamento de conhecimento
* Comunicação clara e objetiva
* Feedback profissional

## Comportamentos Inaceitáveis

Não serão tolerados:

* Assédio ou intimidação
* Linguagem ofensiva ou discriminatória
* Ataques pessoais
* Divulgação de informações privadas sem autorização
* Spam ou conteúdo malicioso
* Publicação de exploits sem divulgação responsável

## Resolução de Conflitos

Problemas de conduta poderão resultar em:

1. Advertência.
2. Restrição temporária de participação.
3. Remoção permanente da comunidade.

A decisão ficará a critério dos mantenedores do projeto.

## Escopo

Este código de conduta aplica-se a:

* Issues
* Pull Requests
* Discussões
* Revisões de código
* Qualquer outro canal oficial do projeto
