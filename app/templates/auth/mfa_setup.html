Cadastrar MFA

Configure seu aplicativo autenticador para proteger o acesso à Certificadora.

Como configurar
  1. Abra o Microsoft Authenticator.
  2. Escolha a opção para adicionar uma nova conta.
  3. Leia o QR Code abaixo com a câmera do aplicativo.
  4. Informe o código de 6 dígitos gerado para concluir o cadastro.

O QR Code é individual e deve ser utilizado apenas no seu dispositivo autenticador.

Digite o código de 6 dígitos exibido no aplicativo autenticador.
🛡

Por que isso é necessário?

A autenticação multifator adiciona uma camada extra de proteção ao seu acesso, reduzindo o risco de uso indevido mesmo que a senha seja comprometida.

1 Confirma sua identidade
2 Protege operações sensíveis
3 Reforça a auditoria do sistema

Caso troque de aparelho ou perca acesso ao autenticador, solicite a redefinição do MFA a um administrador autorizado.
