Visao geral

Aplicacao Flask para gestao de certificados digitais internos, com autenticacao, MFA, RBAC, auditoria, solicitacao, aprovacao, emissao, importacao, monitoramento e revogacao de certificados.

Arquitetura

  • Backend em Flask com templates Jinja2.
  • Persistencia via SQLAlchemy.
  • Autenticacao LDAP/AD opcional ou provedor mock para demonstracao local.
  • Artefatos criptograficos armazenados fora do controle de versao.
  • Auditoria estruturada para eventos sensiveis.

Modo portfolio

O modo demo usa dados ficticios, banco SQLite local e login mock configurado por variaveis de ambiente. Ele nao depende de infraestrutura interna, URLs privadas, credenciais corporativas ou certificados reais. 

DEMO_MODE=true
AUTH_PROVIDER=mock
APP_DATABASE_URL=sqlite:///portfolio_demo.db
AUDIT_DATABASE_URL=sqlite:///portfolio_demo.db

Seguranca

  • CSRF habilitado em formularios.
  • Permissoes aplicadas no backend por decorator de autorizacao.
  • Uploads de CSR limitados e validados.
  • Exportacao PFX/P12 sem senha desabilitada por padrao.
  • Chaves privadas, certificados reais, logs e arquivos locais ignorados pelo Git.

Validacao

Execute antes de publicar ou demonstrar:

python -m py_compile run.py app\__init__.py app\config.py app\models.py
python -m unittest discover -v
